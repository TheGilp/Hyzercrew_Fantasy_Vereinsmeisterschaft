Info zur Punktevergabe

Das Punktesystem setzt sich aus drei Komponenten zusammen:

1 Basis-Punkte für das Gesamtergebnis (Score relativ to Par)

Die Basis-Punkte belohnen das Runden-Endergebnis relativ to Par. Ein Ergebnis von +25 ergibt genau 0 Punkte, während −10 (oder besser) mit 120 Basis-Punkten belohnt wird.

  • −10 oder besser 120 Punkte
  • −7 bis −9 105 Punkte
  • −4 bis −6 90 Punkte
  • −1 bis −3 75 Punkte
  • Even Par (E) 60 Punkte
  • +1 bis +3 45 Punkte
  • +4 bis +8 30 Punkte
  • +9 bis +15 15 Punkte
  • +16 bis +24 5 Punkte
  • +25 oder schlechter 0 Punkte

2 Bahnenbezogene Bonuspunkte

Direkte Boni für herausragende Ergebnisse auf einzelnen Bahnen:

  • Ace (Hole-in-One) +50 Punkte
  • Albatross (−3 auf einer Bahn) +40 Punkte
  • Eagle (−2 auf einer Bahn) +15 Punkte
  • Birdie (−1 auf einer Bahn) +4 Punkte
  • Par / Bogey / Double Bogey 0 Punkte

3 Rundenbezogene Bonuspunkte

Fehlerfreies Spiel und besondere Rundenleistungen werden mit folgenden Bonuspunkten belohnt:

  • CTP (Closest-to-the-Pin) +25 Punkte
  • Bogey freie Runde +10 Punkte
  • OB freie Runde +5 Punkte
  • Turkey (3 Birdies in Folge) +5 Punkte
  • Motivationsbonus (3 Bogeys in Folge – max. 1x pro Runde) +5 Punkte
