Info zur Punktevergabe

Das Punktesystem setzt sich aus zwei Komponenten zusammen:

1 Basis-Punkte für das Gesamtergebnis (Score relativ to Par)

Die Basis-Punkte belohnen das Runden-Endergebnis relativ to Par. Ein Ergebnis von +25 ergibt genau 0 Punkte, während −10 (oder besser) mit 120 Basis-Punkten belohnt wird.

  • −10 oder besser 120 Punkte
  • −7 bis −9 105 Punkte
  • −4 bis −6 90 Punkte
  • −1 bis −3 75 Punkte
  • Even Par (E) 60 Punkte
  • +1 bis +3 45 Punkte
  • +4 bis +8 30 Punkte
  • +9 bis +15 15 Punkte
  • +16 bis +24 5 Punkte
  • +25 oder schlechter 0 Punkte

2 Bonus-Punkte

Damit Spieler auch während der Runde Punkte sammeln und seltene Glanzpunkte belohnt werden, gibt es direkte Boni für spektakuläre Ergebnisse auf einzelnen Bahnen:

  • Ace (Hole-in-One) +50 Punkte
  • CTP (Closest-to-the-Pin) +40 Punkte
  • Albatross (−3 auf einer Bahn) +30 Punkte
  • Eagle (−2 auf einer Bahn) +15 Punkte
  • Birdie (−1 auf einer Bahn) +4 Punkte
  • Par / Bogey / Double Bogey 0 Punkte
